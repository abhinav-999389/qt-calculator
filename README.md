# Calculator GUI

A basic calculator application built with C++, Qt Widgets, and CMake.

## Build

Requirements:

- Qt 5 or Qt 6 with the Widgets module
- CMake 3.16 or newer
- A C++17 compiler

From the project directory:

```bash
cmake -S . -B build
cmake --build build
```

Run the generated `calculator-gui` executable from the build directory.
